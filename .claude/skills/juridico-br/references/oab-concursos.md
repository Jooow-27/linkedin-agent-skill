# Exame da OAB e concursos

## Regra de ouro

Questão de prova cobra a **lei seca e a jurisprudência consolidada até o edital**.
Se houve mudança depois do edital, responda pelo gabarito provável e anote a
mudança em uma linha.

## Questão objetiva

```
Resposta: [letra]
Fundamento: [artigo/súmula exata — uma linha]
Por que as outras estão erradas:
A) [erro em uma linha + dispositivo]
B) ...
Pegadinha: [o detalhe que a banca explorou]
```

Se o enunciado estiver ambíguo ou desatualizado, diga qual seria o gabarito da
banca e qual a resposta correta hoje.

## Discursiva (2ª fase FGV)

Estrutura de resposta que pontua no espelho:
1. Resposta direta (sim/não/qual medida) na primeira frase.
2. Fundamento jurídico **com o dispositivo** (a FGV não pontua artigo sem
   explicação, nem explicação sem artigo em muitos itens).
3. Aplicação ao caso.

## Peça prático-profissional (2ª fase)

Antes de escrever, identifique e mostre em quadro:

| Item | Resposta |
|---|---|
| Peça cabível e fundamento | ex.: Apelação — CPC 1.009 |
| Endereçamento / competência | |
| Legitimidade (partes) | |
| Tempestividade e preparo (se recurso) | |
| Teses (processuais e materiais) | |
| Pedidos (um por tese) | |
| Fechamento | "Local..., data..., Advogado..., OAB..." — **nunca** assinar ou se identificar |

Regras de prova: não inventar dados não fornecidos (usar "...");
cuidado com a peça "armadilha" (ex.: agravo x apelação, contestação x
embargos, RO x RR, RESE x apelação); fundamentar cada pedido.

## Espelho de correção simulado

Quando o usuário enviar resposta para correção, devolva uma tabela
**item do espelho | pontuação possível | atingido? | o que faltou**, nota
estimada e as três correções de maior impacto.

## Concursos

- Indique a corrente majoritária e a minoritária quando a banca costuma
  cobrar divergência (CESPE/Cebraspe: certo/errado com nuance; FCC: lei seca;
  FGV: jurisprudência recente e casos práticos).
- Para questão de jurisprudência, cite o informativo só com nível A ou B.
